# 파주출판단지 산책 코스 · 스탬프 투어

K-뉴딜 아카데미 THC 10/23(금) 기업탐방 자유시간(15:30–17:00)용 안내 사이트예요.

## 들어 있는 파일
- `index.html` : 사이트 전체 (지도, 장소 정보, 길찾기, 스탬프 투어, 오늘 일정)
- `course.png` : 공지용 동선 이미지 (카톡 링크 미리보기 이미지로도 쓰여요)

## 사이트 주소
https://lumieshop.github.io/THC/

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들어요. (이 사이트는 `THC`, 공개 저장소)
2. **Add file → Upload files**로 `index.html`, `course.png`, `README.md`를 올리고 커밋해요.
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 고르고 저장해요.
4. 1~2분 뒤 `https://lumieshop.github.io/THC/` 주소가 생겨요. 이 주소를 단톡방에 공유하면 돼요.

카톡 링크 미리보기에 이미지가 뜨게 하려면 `index.html` 위쪽의
`<meta property="og:image" content="course.png">`를
`https://lumieshop.github.io/THC/course.png`처럼 전체 주소로 바꿔주세요.

## 미리 테스트하기
- 주소 끝에 `?test`를 붙여 열면 (예: `https://lumieshop.github.io/THC/?test`) 위치 확인 없이 스탬프가 찍혀요. 집에서 동작을 확인할 때 쓰세요.
- 테스트로 찍은 스탬프는 스탬프 투어 아래 **스탬프 모두 지우기**로 지울 수 있어요.

## 스탬프 동작 방식
- 장소 정보에서 **인증샷 찍고 스탬프 받기** → 카메라로 촬영 → 휴대폰 위치가 장소 반경 150m(GPS 오차 보정 최대 100m) 안이면 스탬프가 찍혀요.
- 위치 권한을 거부하면 스탬프는 찍히되 '위치 미확인'으로 표시돼요.
- 사진과 스탬프는 각자 휴대폰 브라우저에만 저장돼요. 서버로 올라가지 않아요.
- **인증 카드 만들기**를 누르면 이름, 사진, 스탬프, 시각이 담긴 이미지 한 장이 만들어져요. 집합 때 이 카드를 확인하거나 단톡방에 올리게 하면 돼요.
- 같은 휴대폰이라도 브라우저를 바꾸면(카톡 → 크롬) 스탬프가 이어지지 않아요. 처음 연 브라우저로 계속 쓰도록 안내해주세요.

## 고칠 수 있는 설정 (`index.html` 안 `CONFIG`)
- `radius` : 스탬프 인정 반경(m), 기본 150
- `slack` : GPS 오차 보정 최대치(m), 기본 100
- `goal` : 우수 활동 기준 스탬프 수, 기본 3
- 장소 설명·미션·시간은 `const PLACES = [...]` 부분에서 바꿀 수 있어요.
